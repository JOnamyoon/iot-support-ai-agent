url: https://genai.owasp.org/llm-top-10/

Prompt injection occurs when instructions in user input or external content manipulate an LLM into unintended behavior. LLM applications should treat retrieved or user-supplied content as untrusted data and apply controls around model actions. The OWASP LLM risk guidance also covers insecure output handling, excessive agency, sensitive information disclosure, vector and embedding weaknesses, and related GenAI risks.
