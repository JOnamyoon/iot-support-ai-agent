source_id: STREAMLIT_STATE
title: Streamlit Session State
url: https://docs.streamlit.io/develop/api-reference/caching-and-state/st.session_state

Streamlit Session State stores values that should persist across reruns for a user session. It can hold variables, widget state, and conversation context. Session State is useful because Streamlit reruns a script from top to bottom when users interact with widgets.
