title: OWASP Top 10 2025
url: https://top10.owasp.org/2025/

The OWASP Top 10 is an awareness document for common web application security risks. The 2025 edition includes categories such as broken access control, security misconfiguration, software supply chain failures, cryptographic failures, injection, insecure design, authentication failures, software or data integrity failures, security logging and alerting failures, and mishandling of exceptional conditions.
