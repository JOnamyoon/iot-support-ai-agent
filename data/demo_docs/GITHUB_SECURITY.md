title: GitHub Security Hardening for Actions
url: https://docs.github.com/en/actions/security-for-github-actions/security-guides/security-hardening-for-github-actions

GitHub security hardening guidance for Actions recommends reducing token permissions, protecting secrets, pinning or carefully reviewing third-party actions, and treating pull request or external input as untrusted. CI systems should follow least privilege because workflows can access repository resources.
