title: OWASP API Security Top 10
url: https://api-security.owasp.org/

The OWASP API Security Top 10 focuses on risks that are especially important for APIs. Typical themes include authorization mistakes, authentication problems, unrestricted resource consumption, security misconfiguration, unsafe inventory management, and unsafe consumption of third-party APIs. API security requires validating who can access which object and operation, not only whether a user is logged in.
