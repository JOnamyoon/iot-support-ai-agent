OWASP MCP security guidance addresses risks in systems that connect AI models to external tools and context through the Model Context Protocol. Threats include command execution from untrusted context, tool or model misbinding, context spoofing, insecure memory references, and other failures that can turn model instructions into unsafe external actions.
